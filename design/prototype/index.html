言枢 Messages · Windows 10 Mobile 界面设计稿 v1

设计基准 360 × 640（Windows 10 Mobile / Lumia 950，15254）。黑底 + 系统强调色 + 直角气泡的单强调色体系；除用户消息外，全部过程走左侧轨道，不进气泡。 配套文档：docs/设计稿.md

时间线条目怎么区分
类型规则数据来源默认状态
用户消息 唯一靠右、强调色实心直角气泡，右下小三角尾巴；附件行在气泡上方。 role=user完整显示
思考 左侧虚线圆圈 + 斜体淡紫灰字，表示「推理中」。生成时圆圈缓慢旋转。 reasoning_content折叠为一行摘要
步骤轨道 左侧 2px 实心竖轨 + 方块节点。思考 / 工具 / 读取 / 命令都挂在轨道上。默认只显示最近一步，上方给「显示前面 N 步」折叠条。 think_steps / tool_calls仅最近一步
工具完成 节点由强调色转绿；失败转红并在行内展开错误摘要，附「重试」。 role=tool标题行可见
中间解说 缩进正文块，左侧 2px 深灰竖线，颜色比最终输出暗一档。模型「说话但还没定稿」的内容。 assistant（中间轮）完整显示
最终输出 无气泡、亮色正文，Markdown 全量渲染。代码块深底 + 左侧强调色边 + 语言标签 + 复制按钮。 assistant（末轮）完整显示
系统 / 分隔 居中灰字小字条（如「已加载 12 条更早消息」「上下文已压缩」），可点。 system / 本地事件—
错误 左侧红色竖轨 + 红标题 + 可展开详情 + 「重试」（复用同一 clientMessageId，不产生重复任务）。 本地异常 / HTTP展开
审批 / 需要你处理 不进列表，固定条钉在会话顶部（黄条），点开进全屏表单。处理完回原位。 notice / permission常显至处理

这一稿相对两个源项目改了什么

改动原来现在
导航Lumina.Agent：SplitView 三栏 + 18 个页面；Agents Anywhere：两层嵌套 Pivot三页根 Pivot，会话页不再嵌套 Pivot，文件与终端类功能下沉到二级页
消息呈现全类型走气泡 + 推理折叠只有用户消息是气泡；思考 / 工具 / 中间解说走左侧轨道，默认只露最近一步
生成中的动作发送 / 停止追加（steer，不打断）+ 停止；长按追加变打断
审批底部滑出面板全屏页 + 会话顶部固定提醒条
档案无档案概念，靠 Project 兼做档案 = 工作区一个文件夹，含人设 / 记忆 / 会话 / 文件，支持角色卡导入导出
记忆三套并行，互不同步会话摘要 + 档案池 + 可选全局池
主题主题文件是死代码且语法有误显式合并的设计令牌体系，颜色 / 字号 / 间距 / 圆角全部命名化
