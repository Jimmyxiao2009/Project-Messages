言枢 Messages · W10M / Modern 界面设计稿 v2

依据 docs/UI-HANDOFF.md 与 docs/设计稿.md，按 Windows 10 Mobile（15254）的 Modern 设计语言重画全部页面与关键状态。 画板 360×640 有效像素，包含状态栏（24）与软件导航栏（48），所以应用实际可用高度是 568；工具栏可切 320 / 430 宽、硬件按键机型、浅色主题与任意系统强调色。 只用系统字体（Segoe UI + Microsoft YaHei UI）与 Segoe MDL2 Assets 图标，不引入任何第三方库。旧稿 design/prototype 与 design/modern-mobile 均未改动。

W10M / Modern 规范落点（XAML 实现时照这张表）
项本稿做法落到 XAML
返回手机上不画返回箭头，一律走系统导航栏 / 硬件返回键；优先级：关弹层 → 退会话 → 收搜索 → 交给系统。SystemNavigationManager.BackRequested；桌面用 AppViewBackButtonVisibility.Visible 在标题栏显示返回。
根导航三页 Pivot：小标题「言枢」+ 24px SemiLight 头。选中的头轮转到最左，未选的用 MidBrush，无下划线。系统 Pivot 默认样式（15254 本来就是轮转、无下划线），只改 Foreground。
子页标题12px 上标签（所属档案 / 上级）+ 24px SemiLight 页名，不加色块。会话页例外：48px Chrome 顶栏，省高度。新增样式 PageOverline / PageTitle；会话顶栏沿用 TopBarHeight 48。
底部应用栏CommandBar 48 高、主命令 ≤ 3 个靠右、标签只在展开时出现，二级命令在展开后从上方弹出。会话页没有 CommandBar。CommandBar ClosedDisplayMode="Compact"；超出的全进 SecondaryCommands（主命令不会自动溢流）。
控件形态全部直角。按钮 BaseLow 底；TextBox 2px 边框，聚焦白底黑字 + 强调色边；ToggleSwitch 44×20 + 「开 / 关」；CheckBox 20px 方框；Slider 8×24 竖条滑块；ProgressBar 4px；不定进度用五点流动，ProgressRing 用点环。14393 的 Control 没有 CornerRadius，系统控件天然直角；Design.xaml 里 CardCornerRadius / ControlCornerRadius 建议改 0，与控件一致。
设置项开关一律「标题在上、开关在下」，不再用负边距把 ToggleSwitch 塞到右边（旧项目的 Margin="0,0,-90,0"）。ToggleSwitch 只用于立即生效的设置；要按按钮才提交的一次性选项（导入选项、备份内容、分支选项）用 CheckBox。ToggleSwitch.Header + 说明 TextBlock。
列表行无 chevron、无分隔线；靠标题 + 副标题（写当前值）表达可点；按下有倾斜反馈。状态只靠 4px 左色条：警告=需要你处理、强调=运行中、错误=失败。ListView 默认 ListViewItemPresenter 自带 PointerDownThemeAnimation。
弹层ContentDialog 贴顶全宽、按钮等分；MenuFlyout 全宽；下拉选项多时进全屏选择页（20px 大字条目，选中项强调色字）。ContentDialog、MenuFlyout、ComboBox（手机上 > 5 项自动全屏）/ ListPickerFlyout。
后台进度生成中、备份中等在状态栏显示五点进度 + 文字；页面里只放行内细进度，不用遮罩挡屏。StatusBar.ProgressIndicator（先 ApiInformation.IsTypePresent）；桌面退化为页内 ProgressBar。
软键盘依赖整页上移；编辑类页面在键盘弹出时把「保存」提到标题行，底部固定按钮不被挡。InputPane.Showing / Hiding 只切换「保存」位置，不改布局结构。
字体与刻度W10 type ramp：Caption 12 · Body 15 · Base 15 SemiBold · Subtitle 20 · Title 24 SemiLight · Subheader 34 Light。页边距 12（W10M 手机标准）。见下表的令牌改动建议。
颜色单强调色；一屏只有一个实心强调色焦点（主按钮或用户气泡）。头像用强调色柔底，不抢焦点。浅色主题按系统浅色（白底、#E6E6E6 Chrome）。ThemeDictionaries 拆 Dark / Light；同文件内用 {ThemeResource}。
